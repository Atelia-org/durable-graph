额外 payload 容忍度与平均重建 payload 的关系。理想稳态模型 · 非实测数据。

连续模型可取小数；产品参数只接受整数。初始显示 L=5，对应当前库默认阈值。

ε = 1 / (L − 1)
R = 1 + 1 / (2ε)

B = 当前完整 Base payload；R = 平均重建 payload / B。
ε 以小数代入：25% = 0.25。按刚好用满容忍度的边界取值。

容忍度与重建：一条双曲线

横轴 ε 越往左，额外写入越少；相应的平均重建 payload 越大。

L = 5：容忍额外 25% payload，对应平均重建 3B。

随 L 增大，开销递减

ε = 1/(L−1)，导数为 −1/(L−1)²。

随 L 增大，重建线性增长

R = (L+1)/2，L 每加 1，平均重建增加 0.5B。

模型的前提与读图边界
  • 单个对象的 Base 大小 B 大致稳定；每次更新的 Delta d 较小且大致稳定；连续运行足够长。
  • 周期内均匀取样重建；预算不推迟可选 Base。两次 Base 之间约积累 (L−1)B 的 Delta。
  • 忽略初始 Base 的有限历史影响、Base 替代当次小 Delta 的修正，以及离散更新、严格大于和 D 上界造成的偏差。
  • 只讨论对象 payload；不计共享 frame、map、Journal 等开销。曲线不表示实际磁盘 I/O、读取耗时或整个仓库的空间倍率。
  • 这里的 ε 是长期摊销模型量，与产品单次选择的 BaseBudgetPercent 不是同一预算。模型中的 L 也不构成实际冷读放大的硬上限。
  • L=1 对应的该小 Delta 渐近公式发散，不能用它描述有限 d 下每次写 Base 的实际开销。本页展示 L∈[2,21]，ε∈[5%,100%]。
